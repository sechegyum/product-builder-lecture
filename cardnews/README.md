# Snapvest 카드뉴스 템플릿

인스타그램 캐러셀 5장 세트. **디자인은 고정, 값만 교체**해서 매번 생성한다.

```
python3 generate.py config.json out
```
→ `out/` 에 1080×1080 SVG 5장 생성

---

## 1. 카드 구성

| # | 파일 | 헤드라인 (고정 문형) | 역할 |
|---|---|---|---|
| 1 | 1-cover.svg<br>1-cover-left.svg | `{종목}는 왜 / 하루 만에 / N% 올랐을까?` | 질문 던지기. **정렬만 다른 두 장**이 나온다 |
| 2 | 2-company.svg | `{종목}는 어떤 회사일까?` | 배경 |
| 3 | 3-reason.svg | `그래서 왜 올랐을까?` | 답 |
| 4 | 4-chart.svg | `지표는 지금 어디쯤일까?` | 검증 |
| 5 | 5-cta.svg | `그럼 내부자는 지금 사고 있을까?` | 유도 |

**질문 → 배경 → 답 → 검증 → 답 안 준 질문** 순서.
5번이 유료 항목(내부자·지분)으로 끝나기 때문에 사이트 유입이 발생한다.

## 2. 디자인 규칙 (수정 금지)

**색상**
```
배경 그라데이션   #FBF9FF → #EFEAFC
포인트 그라데이션 #4A6CF7 → #B455C4 → #E0568A
강조 텍스트       #B455C4
본문 진한         #2B2B3A
본문 중간         #8B85A8
본문 흐린         #9691B8 / #B9B3D6
캔들 상승 / 하락  #E0568A / #5A8FD6
```

**레이아웃**
```
캔버스        1080 × 1080
좌우 기준선    x=80 / x=1000
흰 카드        rx 52, 내부 패딩 56 (좌 136 · 우 944)
그라데이션 바   220×12 (표지만 240×14), rx 절반
헤더           y=118 고정
푸터           y=1046 고정
```

**공통 요소**
- 상단 `✦ SNAPVEST AI SIGNAL` + 날짜
- 헤드라인의 **핵심 단어만 마젠타**
- 헤드라인 아래 그라데이션 바
- 우측 하단 `snapvestai.com` 그라데이션

**1번 표지 헤드라인 (2026.08 변경)**
- **우측 정렬**(`1-cover`, x=1000)과 **좌측 정렬**(`1-cover-left`, x=80) 두 장이 나온다.
  인스타 피드에서 좌측이 UI 에 가릴 때가 있어 둘 중 골라 쓴다
- 88px · 첫 줄의 **종목명만 900**, 나머지는 700
- 종목명은 `company_ko` 로 자동 인식한다. `cover_line1` 이 종목명으로 시작하지
  않으면 줄 전체가 700 으로 나온다
- 그라데이션 바도 우측(x=760)

## 3. config.json 필드

### 기본
| 키 | 설명 | 예 |
|---|---|---|
| `date` | 카드 우상단 날짜 | `08.20` |
| `ticker` / `exchange` | 티커 · 거래소 | `MRNA` / `NASDAQ` |
| `company_ko` / `company_en` | 한글명 · 영문명 | `모더나` / `Moderna` |
| `price` / `change` | 현재가 · 등락률 | `$174.3` / `+170%` |

`change` 가 `-` 로 시작하면 색이 자동으로 파랑으로 바뀐다.

### 1번 표지
| 키 | 설명 |
|---|---|
| `cover_line1~3` | 헤드라인 3줄. **3번째 줄이 마젠타** |
| `cover_fact1~2` | 카드 하단 요약 2줄 |
| `logo` | 흰 카드 왼쪽 원형 로고. **비워두면 빈 원**. `make_photos.py` 가 만든 `assets/logo-chip.png` 를 쓴다 |

### 2번 기업 설명
| 키 | 설명 |
|---|---|
| `photo_company` | 이미지 경로 (**1000×290**). 비워두면 점선 플레이스홀더 |
| `desc_lead1~2` | 굵은 설명 2줄 |
| `desc_sub` | 흐린 보조 1줄 |
| `desc_sub2` / `desc_sub3` | 보조 2·3번째 줄. **없으면 그 줄이 통째로 빠진다** |
| `segments` | 사업 부문 칩 3개. **없으면 칩 줄이 통째로 빠진다** |
| `market_cap` / `volume` / `week52` | 하단 3열 지표 |

### 3번 급등 이유
| 키 | 설명 |
|---|---|
| `photo_reason` | 이미지 경로 (비우면 플레이스홀더) |
| `reason_verb` | `올랐을까` / `떨어졌을까` |
| `reason_lead1~2` | 굵은 핵심 2줄 |
| `reason_body` | 상세 3줄 배열 |
| `reason_source` | 출처 표기 |

### 4번 차트 + 지표
| 키 | 설명 |
|---|---|
| `candles` | 실제 OHLCV 배열 `[[o,h,l,c,vol비율], ...]`. **있으면 이걸 우선 사용** |
| `candle_count` | 자동 생성 시 봉 개수 (30~60 권장) |
| `candle_start` / `candle_end` | 자동 생성 시 시작가 · 마지막 종가 |
| `seed` | 자동 생성 난수 시드 |
| `gauges.mfi/rsi/bb` | 0~100 / 0~100 / 0~1 |
| `gauges.*_status` | 각 게이지 우측 상태 문구 |
| `gauge_note` | 하단 한 줄 요약 |

> **실서비스 연동 시 `candles` 에 실제 OHLCV 를 넣을 것.**
> 자동 생성은 시안용이며 실제 주가가 아니다.

### 5번 마무리
| 키 | 설명 |
|---|---|
| `cta_items` | 흰 카드 안 3줄 |

버튼 아래 **로그인 없이도 10회 무료**, 우측 하단 **snapvestai.com** 은
`generate.py` 에 고정돼 있다. 바뀌면 `promo.json` · `SNS-TEMPLATE.md` 도 같이 고친다.

## 4. 사진 넣는 법

`photo_company` / `photo_reason` 에 파일 경로를 넣으면 **SVG 안에 base64로 삽입**된다.
비워두면 점선 플레이스홀더가 나오므로 Canva 등에서 직접 얹으면 된다.

원본이 작을 때는 `photos/` 에 넣고 전처리기를 돌린다.

```
python3 make_photos.py      # photos/ -> assets/ (1000x340, 1000x372)
```

슬롯이 1000px 라 작은 사진을 그대로 늘리면 뭉개진다.
전처리기는 같은 사진을 **흐린 배경 + 최소 배율 전경** 으로 겹쳐 깔끔하게 채운다.
`JOBS` 목록의 파일명만 바꿔서 쓰면 된다.

같은 스크립트가 표지 원형 로고(`assets/logo-chip.png`)도 만든다.
`CHIP` 을 셋 중 하나로 설정한다.

| 설정 | 언제 |
|---|---|
| `{"src": "파일명.jpg"}` | 로고 원본이 있을 때 |
| `{"src": "파일명.jpg", "crop": (l,t,r,b)}` | 로고에서 심볼만 떼어 쓸 때 (워드마크는 원 안에서 안 읽힌다) |
| `{"text": "R"}` | **로고가 없는 티커.** 토스처럼 첫 글자만 박는다 |
| `None` | 빈 원 |

흰 여백을 잘라내고 배경을 라벤더(`#EFEAFC`)로 치환하기 때문에
**흰 배경 위에 올린 로고 원본**이 가장 잘 나온다. 종목 로고는 Brandfetch 로 조회.
SPAC·신규 상장처럼 로고가 없는 종목이 흔하니 그때는 레터마크를 쓴다.

- 가로로 넓은 이미지가 유리 (2번 1000×290, 3번 1000×372)
- 글자가 박힌 사진은 피할 것
- **언론사 기사 사진은 저작권 문제.** 무료 스톡이나 회사 공식 자료 사용
- 종목 로고는 Brandfetch 로 티커 조회 가능

## 5. 문구 원칙

- **결론을 내리지 않는다.** `지금이 매수 타이밍` ✕ → `공매도가 8.2%p 늘었어요` ⭕
- **모르는 건 모른다고 쓴다.** `자료 없음` 표기를 그대로 노출
- **숫자를 제목에 넣는다.** `공매도 급증` 보다 `공매도 19.3%, 2주 만에 8.2%p`
- 말투는 `~어요`, `~습니다` 로 통일
- **기사 헤드라인을 그대로 복사하지 않는다.** 사실만 자기 문장으로 서술

## 6. 내보내기

SVG 그대로 올리면 폰트가 깨질 수 있다.
**Pretendard 가 설치된 환경에서 PNG(1080×1080)로 변환**해서 업로드할 것.

```
python3 render.py           # out/*.svg -> png/*.png
```

헤드리스 크롬으로 렌더한다. `render.py` 의 `CHROME` 경로만 환경에 맞게 고치면 된다.
Pretendard 는 시스템 폰트로 설치돼 있어야 한다 (`fc-list | grep -i pretendard`).

사진 슬롯에 일봉 차트를 넣고 싶으면 `config.json` 에 실제 `candles` 를 채운 뒤

```
python3 make_chart.py 1000 340 chart-company.png   # 2번 카드 슬롯
python3 make_chart.py 1000 372 chart-reason.png    # 3번 카드 슬롯
```

카드 색상 토큰을 그대로 쓰기 때문에 사진 자리에 넣어도 톤이 어긋나지 않는다.

### 전체 흐름

```
photos/ ──make_photos.py──> assets/ ──┐
                                      ├─generate.py──> out/*.svg ──render.py──> png/*.png
config.json ──────────────────────────┘
```
