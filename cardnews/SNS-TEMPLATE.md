# SNS 글귀 뼈대

카드뉴스 5장과 한 세트로 매 회차 같이 만든다. 결과물은 그 회차 폴더의 `sns.md` 에 남긴다.

---

## 0. 첫머리 인사 (인스타 · 블로그 공통 · 고정)

인스타 캡션과 블로그 본문은 **반드시 이 두 줄로 시작한다.**

```
안녕하세요. 스냅베스트(Snapvest)입니다.
오늘 다루어볼 종목은 {회사명}({티커})입니다.
```

**쓰레드는 예외다.** 쓰레드는 인사 없이 `나스닥에 상장된 …` 으로 바로 들어간다.

---

## 1. 인스타그램 — 캐러셀 캡션

```
안녕하세요. 스냅베스트(Snapvest)입니다.
오늘 다루어볼 종목은 {회사명}({티커})입니다.

{가장 센 숫자 하나 + 그 숫자가 누구에게 무슨 일이었는지}

{날짜}에 {회사}({티커}) 주가가 {전일 종가}에서 {종가}로 마감했습니다.
{수급 숫자 2개}

이유는 {한 단어}였습니다.
{무슨 일인지 3~5줄. 숫자를 문장 안에 넣는다}

다만 {아직 공개되지 않은 것}.
"{공개된 사실 한 문장}"만 나온 상태예요.

나중에 다시 볼 수 있게 저장해두세요 🔖

※ 투자 권유가 아닙니다. 모든 판단과 책임은 본인에게 있어요.

{해시태그 9개 내외}
```

**해시태그**

| 그룹 | 태그 |
|---|---|
| 고정 | `#미국주식` `#해외주식` `#주식공부` `#스냅베스트` |
| 회차별 | 종목명 · 티커 · 거래소 · 섹터 · 이슈 키워드 |

`#주식` `#투자` 같은 초대형 태그는 몇 초 만에 밀려서 안 쓴다. 30개 채우지 않는다.

**태그보다 중요한 것** — 인스타 검색이 캡션 본문을 읽는다.
`{회사명}` `{회사명} 주가` `{티커}` `미국주식` 을 캡션 안에 자연스럽게 넣는다.

## 2. 쓰레드 — 단일 포스트

체인으로 쪼개지 않는다. **한 포스트에 카드 5장을 붙이고**, 짧은 문단 네 덩어리로 끝낸다.

```
나스닥에 상장된 {회사명}({티커}) 이야기입니다. {날짜} {가격}이던 주가가 {날짜} {가격}로 {끝났어요 / 올랐어요}.

{이 회차에서 가장 센 사실 한 문장}

{그 사실을 한 번 더 풀어주는 한 줄}
{기간} 만에 {등락률}입니다 ⬇️
```

**규칙**

- 문단마다 빈 줄. 한 문단은 1~2문장을 넘기지 않는다
- 첫 줄은 `나스닥에 상장된 …` 처럼 **종목 소개부터**. 숫자로 시작하지 않는다
- 마지막 줄은 **숫자 + `⬇️`**. 카드를 넘겨 보라는 신호다
- 해시태그를 쓰지 않는다. 태그는 `미국주식` / `국내주식` 하나만
- 링크는 본문에 안 넣는다. 카드 5번 장에 이미 있다
- 안을 2~3개 뽑아 고르게 한다 (모순형 / 수급형 / 위치형)

**왜 체인이 아닌가**

체인은 각 포스트가 따로 노출돼서 앞뒤가 끊긴다.
단일 포스트는 첫 화면에서 훅과 카드가 같이 보이고, 넘길 이유가 `⬇️` 한 글자로 정리된다.

## 3. 블로그 (네이버) — 회차별 `blog.md`

카드 5장을 문단 사이에 순서대로 끼워 넣는 긴 글. 카드뉴스와 같은 사실만 쓴다.

**제목** — 핵심 키워드를 **앞쪽 8글자 안**에, 공백 포함 30자 안팎, 숫자 포함.
검색어를 그대로 넣는다: `{종목명} 주가`, `{테마} 관련주`, `{종목명} 급등 이유`.
안을 3~4개 뽑아 고르게 한다.

**태그 30개 — 고정. 회차마다 바꾸지 않는다**

```
#재테크 #비트코인 #주식투자 #주식공부 #주린이 #매매일지 #주식초보 #주식정보 #코스피 #재테크그램 #나스닥 #주식매매 #수익률 #미국주식 #주식차트 #투자공부 #주식단타 #제테크 #해외주식 #가치투자 #단타매매 #트레이딩 #스캘핑 #장기투자 #투자스타그램 #직장인투자 #주식매매일지 #스윙매매 #주식수익 #트레이더
```

노출량 기준으로 고른 세트라 회차 내용과 무관한 태그가 섞여 있어도 그대로 쓴다.
`#제테크` 는 의도된 오타 검색어다. 네이버 상한이 30개라 더 넣지 않는다.

**본문 뼈대** (카드 순서 그대로)

| 위치 | 카드 | 내용 |
|---|---|---|
| 도입 | 1 표지 | 종가·등락률·거래량 → `그런데 왜 올랐을까` 로 끊기 |
| 1장 | 2 기업 | 어떤 회사인지 · 이 종목이 알려진 이유 |
| 2장 | 3 이유 | 무슨 일이 있었는지 + **인과 고리를 화살표로** |
| 3장 | 4 지표 | 표로 정리 · 통념과 어긋나는 지점을 짚기 |
| 마무리 | 5 CTA | 불릿 정리 → 서비스 한 줄 → 면책 문구 |

**블로그가 SNS 와 다른 점**

- 길이가 무기다. 1,000자 이상 써야 검색에 걸린다
- **마크다운 표를 쓰지 않는다.** 네이버 편집기에 붙여넣으면 `|` 가 그대로 나와 깨진다.
  항목은 `▪ 이름 — 값` 줄로 쓰고, 두 값을 비교할 땐 아래에 두 줄로 들여쓴다
- **공백으로 줄을 맞추지 않는다.** 연혁·시간대처럼 날짜를 세로로 정렬하고 싶어도
  붙여넣으면 공백이 무너져 들쭉날쭉해진다. **연혁도 `▪ 날짜 — 내용` 한 줄씩**이다.

  ```
  ✕  2023년 6월  대웅제약과 국내 판권 계약 체결
     2023년 9월  시리즈C 207억원 투자 유치

  ⭕ ▪ 2023년 6월 — 대웅제약과 국내 판권 계약 체결
     ▪ 2023년 9월 — 시리즈C 207억원 투자 유치
  ```

  같은 날짜가 세 줄 이상 이어지면 한 줄로 합친다 (`2026년 8월` 셋 → 둘).
  **토스 글은 예외다** — 거기는 공백 정렬이 그대로 살아서 연혁을 표처럼 둔다
- 인과를 화살표로 그린다 (`A 상승 → B 증가 → C 개선 → D 주가`)
- 이미지마다 **대체 텍스트**를 넣는다. 검색 노출에 반영된다
- 면책 문구를 반드시 단다

## 3-2. 토스 커뮤니티 — 짧은 글

블로그로 보내는 채널이다. **맨 앞 네 줄은 고정**한다.

```
{회사명}({티커}) 관한 이야기입니다.
자세한 내용은 블로그에 조금 더 자세히 올려두었습니다.

관심있게 보시는 종목들 중 원하시는 종목 요청해주시면
반영해서 작성해보도록 할게요.
```

**줄바꿈까지 이대로다.** 둘째 줄 뒤에 빈 줄이 들어가고, 넷째 줄은
`요청해주시면` 에서 끊는다. 토스 화면 폭에 맞춰 잡은 자리다.

이어서 소제목 세 개로만 끊는다. 길면 안 읽힌다.

| 순서 | 소제목 | 내용 |
|---|---|---|
| 1 | ■ 어떤 회사인가 | 뭘 하는 회사인지 → 규모(발행주식·시가총액) |
| 2 | ■ 회사 역사 | `연월 + 한 줄` 로 7~9줄. 수치는 최소한만 |
| 3 | ■ 이번 급등 | 등락률 · 거래량 → 이유 → 단서 한 줄 |
| 4 | ■ (이 회차의 핵심) | 구조·계산처럼 이 회차만의 대목이 있으면 여기 |
| 5 | ■ 함께 볼 지점 | 리스크 2~3개 → 마무리 한 줄 |

**기업 개요와 연혁이 맨 앞이다.** 커뮤니티는 종목을 처음 보는 사람이 많아
"뭐 하는 회사인지" 가 먼저 와야 뒤가 읽힌다. 연혁에 표를 쓰지 않는다.

**어려운 말과 잔숫자를 뺀다.** 이게 이 채널의 핵심이다.

| 쓰지 않는다 | 대신 |
|---|---|
| 13G · 13D | "경영에 참여하겠다는 건 아니고 단순 투자" |
| 계속기업 존속 의문 | "앞으로 1년을 버틸 수 있을지 걱정된다고 공시에 적어뒀습니다" |
| 나스닥 최소주가 미달 통지 · 10거래일 연속 | "1달러를 넘지 못하면 상장이 위태롭다" · "2주 동안" |
| 조정 EBITDA · 부착률 · 발행주식 수 | 통째로 뺀다 |

- **수치는 표 블록으로 묶는다.** 문장에 흩어 놓으면 길어지고 눈에도 안 든다.
  묶으면 같은 숫자를 절반 길이에 담는다. 토스는 공백 정렬이 살아 있어 된다.

  ```
  ✕  공모가를 희망 범위 하단보다 23% 낮춘 1만원으로 확정했고,
     기관 수요예측은 63.41 대 1, 일반청약은 2.85 대 1이었습니다.

  ⭕   공모가         10,000원 (희망밴드 하단 대비 -23%)
      기관 수요예측   63.41 대 1
      일반청약       2.85 대 1
  ```

- **설명은 한 번만.** 표에 적은 숫자를 아래 문장에서 다시 풀지 않는다.
  풀어야 하는 건 **뜻이 안 보이는 값 하나뿐**이다 (예: 의무보유확약 10.93%
  → "나머지 89%가 첫날부터 매물로 나올 수 있었다는 뜻").
- **1,000자 안쪽. 소제목마다 서너 줄.** 커뮤니티는 스크롤로 지나가는 자리라
  길면 첫 소제목에서 닫힌다. 더 설명하고 싶으면 늘리지 말고 **블로그로
  넘긴다** — 그러라고 첫 줄에 블로그를 걸어 둔 것이다
- **톤은 두 층이다.** 맨 앞 네 줄(소개·요청 안내)은 대화체 고정 문구,
  **본문은 전문 톤**으로 `~합니다` `~입니다` 로 끝낸다. `~거든요` `~고요` 는 본문에 쓰지 않는다
- 해시태그를 쓰지 않는다. 링크도 넣지 않는다 (블로그로 보내는 건 첫 줄 문구가 한다)
- 결론을 내리지 않는 건 다른 채널과 같다
- 면책은 `※ 투자 권유가 아닙니다.` 한 줄로 줄인다

## 4. 공통 원칙

- **결론을 내리지 않는다.** `지금이 기회` ✕ → `아직 위험비도 p값도 안 나왔어요` ⭕
- **"아직 모르는 것" 을 반드시 넣는다.** 급등 소식은 이미 다 봤고, 안 나온 정보를 짚는 글이 퍼진다
- 첫 두 줄에 전부 건다
- 투자 권유 아님 문구를 끝에 단다
- **서비스 홍보를 글귀에 넣지 않는다.** 아래는 전부 **카드에만** 들어간다.
  블로그·인스타·쓰레드·토스 어디에도 쓰지 않는다.

  ```
  그럼 내부자는 지금 사고 있을까?          ← 5번 카드 헤드라인
  지분 구조 · 내부자 매매 · 최근 공시까지…   ← 5번 카드 항목
  snapvestai.com                          ← 5번 카드 우측 하단
  숫자는 코드가, 해석은 AI가.               ← 5번 카드 좌측 하단
  로그인 없이도 N회 무료                    ← 아예 안 쓴다
  ```

  카드에 이미 다 적혀 있는 말을 글귀에서 또 읽히면 광고로 읽힌다.
  글은 사실만 두고 끝낸다 — 링크가 필요하면 카드가 대신한다.
- 기사 헤드라인을 복사하지 않는다

## 5. 올리는 시간

| 채널 | 시간 | 이유 |
|---|---|---|
| 인스타 | 평일 오전 7~9시 | 미장 마감이 한국 새벽 5시 · 출근길과 겹침 |
| 쓰레드 | 밤 9~11시 | 같은 소재를 시간차로 양쪽에 쓴다 |
| 블로그 | 당일 아무 때나 | 검색 유입이라 시간보다 제목이 중요하다 |

이슈성이라 하루 지나면 도달이 급감한다. **당일 아침에 올린다.**

## 6. 올리기 전

- [ ] 카드 5장 대체 텍스트 설정 (검색에 잡힘)
- [ ] 첫 장이 피드 썸네일로 말이 되는지
- [ ] 캡션에 결론·매수 권유가 없는지
- [ ] 첫 댓글에 질문 하나 남기기
