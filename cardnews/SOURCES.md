# 바이오덱사 (Biodexa Pharmaceuticals · BDRX · 나스닥 ADR) — 2026.09.11 회차 출처

**국내 주식이 아니다.** 영국 웨일스 카디프 소재 임상단계 바이오텍.
구 사명 Midatech Pharma plc. 나스닥에는 ADR 로 상장돼 있다.

## ★ 이번 회차는 프리마켓이 아니다 — 정규장 확정값이다

지난 세 회차(BRNX·OLB·MGN)는 전부 프리마켓/데이마켓 기준이었다.
**이번은 다르다.** 토스 헤더가 `$1.30 · 지난 정규장보다 +$0.63 (96.9%)` 이고,
일별 시세 최신 행이 `09.11 $1.30 +96.93%` 다. 9/12 오후 2시 56분 화면인데
움직임이 없다 — **9/11 정규장이 확정으로 닫힌 값**이다.

**그래서 카드에 프리마켓 표기를 넣지 않았다.**

## ★ 기준값 — 차트 마커 두 개가 확정한다

주가가 $0.66~$1.30 대라 표기 종가(소수 둘째 자리)로도 1센트가 1.3% 다.
그래도 등락률로 역산했고, 기준값은 서로 독립인 두 마커가 같은 답을 낸다.

```
$0.61 (+113.1%, 26.09.10 저점)  →  0.61 × 2.131  = $1.2999
$4.75 (-72.6%,  26.05.08)       →  4.75 × 0.274  = $1.3015
토스 헤더                          $1.30 = 1,739원 (환율 약 1,338원)
```

역산 종가 16일 중 12일이 표기와 일치하고, 어긋난 4일은 전부 1센트 차이다.
**시·고·저는 토스 모바일 표에 없어 전일 종가를 시가로 삼았다.**

## ★★ 거래량 8.1배 왜곡 — 세 번째 발견이다

`거래대금 ÷ 거래량 = 평균 체결가` 검산. 15일 중 14일이 0.95~1.09 로 맞는데
**8월 25일 하나만 종가의 0.12배**로 나온다.

```
08.25   거래량 16,610,969주 · 거래대금 $2,4xx,xxx → 평균 $0.1445 (종가 $1.18)
        → 8.1배 어긋남
```

**같은 배율이 세 번째다.**

```
MGN  08.20   8.1배
MGN  09.02   8.2배
BDRX 08.25   8.1배
```

**종목이 다르고 날짜가 다른데 배율이 같다.** 토스 일별 시세에서 거래량이
크게 튀는 날에 반복되는 데이터 문제로 보인다. 원인은 특정하지 못했다.

⚠ 다만 **9/11 의 1억 4,244만 주는 표기값을 그대로 쓴다.** 근거 두 개.

1. 화면의 `거래량(20)` 이동평균이 **8.14M** 인데, 9/11(142M)과 8/25(16.6M)를
   표기값으로 넣어야 그 값이 나온다 (16일 평균 10.10M → 20일 약 8.1M)
2. 대표님 자료도 독립적으로 `1억 4,040만 ADS` 를 적고 있다
   (토스 1억 4,244만과 1.4% 차이. 자료 쪽이 반올림한 것으로 보인다)

**글귀에서 8월 25일 거래량은 인용하지 않는다.**

## ★ MFI 99 는 토스 값을 썼다 — 내 계산은 89.62 다

| 지표 | 카드 값 | 근거 |
|---|---|---|
| MFI(14) | **99** | 토스 화면 99.04 |
| RSI(14) | **51** | 직접 계산 51.1 |
| 볼린저 %B | **0.91** | 직접 계산 |

```
볼린저   중심 $0.9549 · σ 0.2114 · 하단 $0.5321 · 상단 $1.3777
```

**왜 MFI 만 토스 값을 썼나.** 종가만으로 계산하면 89.62 가 나온다. 차이의
원인은 8월 25일이다.

```
내 계산 (종가 기준)   8/25 는 종가가 -1.66% 이므로 자금 유출로 잡힌다
                      → 유출 $21.5M 중 $19.6M 이 그 하루
토스 (대표가 기준)    대표가 (고+저+종)/3 을 쓰므로, 8/25 장중 고가가 높았다면
                      같은 날이 유입으로 뒤집힌다 → MFI 가 99 로 올라간다
```

$19.6M 을 유출에서 유입으로 옮기면 **99.1%** 가 나온다. 토스의 99.04 와 맞는다.
**토스가 갖고 있는 고가·저가를 나는 갖고 있지 않아 재현할 수 없다.**
독자가 앱에서 보는 값이 99.04 이므로 카드에는 그쪽을 썼고,
`gauge_note` 에 `MFI 는 토스 표기값이에요` 로 밝혔다.

**어느 쪽이든 결론은 같다.**

```
계산 창 자금 유입     $185.4M
  중 9/11 하루        $185.2M  (100%)
```

**MFI 99 는 "돈이 꾸준히 들어온다" 가 아니라 "하루가 2주치를 통째로 채웠다" 다.**

## ★ RSI 51 이 이 회차의 핵심이다

MFI 99 인데 RSI 51 이다. **직전 14거래일이 대부분 하락이었기 때문**이다.
8/20 $1.26 에서 9/10 $0.66 까지 내려오다가 9/11 하루에 되돌렸다.

```
가격 모멘텀(RSI)   51 · 중립       ← 14일 낙폭을 하루가 겨우 상쇄한 수준
자금 흐름(MFI)     99 · 유입 극단   ← 그 하루의 거래량이 전부다
볼린저 %B          0.91 · 밴드 안   ← 상단($1.38)을 아직 안 뚫었다
```

**돈은 극단으로 들어왔는데 가격은 제자리로 돌아온 것뿐이다.**

**발행주식 199만 주짜리 종목에 1억 4천만 주가 거래됐다.**

## ⚠ 자료의 `52주 고점 대비 -98.9%` 를 고쳤다

```
52주 범위 $0.76 ~ $59.40
$0.66 (9/10 종가) 기준   0.66 / 59.40 − 1 = -98.9%   ← 자료의 값
$1.30 (9/11 종가) 기준   1.30 / 59.40 − 1 = -97.8%   ← 카드에 쓴 값
```

**자료는 급등 전 가격으로 계산한 값이다.** 시세 기준일이 9/11 이므로
카드는 -97.8% 로 넣었다.

⚠ 52주 고가 $59.40 은 **4월 주식병합을 거친 뒤의 환산값**이다.
병합 전 기준으로는 훨씬 크다. 글귀에서 이 값을 쓸 때 `병합 반영 기준` 을 붙인다.

## ⚠ 사진 배치를 바꿨다

받은 사진 두 장이 **둘 다 MTX110(뇌종양) 관련**이고, 이번 급등 사유는

**FAP·대장 쪽 이미지를 받으면 3번을 갈아 끼우는 게 맞다.**
