# Claude Code 요청용 프롬프트

## 새 종목 카드뉴스 만들기

```
cardnews/ 폴더의 generate.py 와 README.md 를 읽어줘.

오늘 카드뉴스를 만들 거야.

[종목]
티커:
회사명(한글/영문):
거래소:
현재가 / 등락률:
시가총액:
거래량 (평균 대비 몇 배):
52주 위치:

[급등/급락 사유]
핵심 한 줄:
상세 (200자 내외):
출처:

[지표]
MFI / RSI / 볼린저 %B:
공매도 잔고 변화:

[차트]
최근 46일 OHLCV (있으면 첨부, 없으면 시작가·종가만)

위 값으로 config.json 을 만들고 generate.py 를 실행해줘.

[규칙]
- generate.py 의 디자인 코드는 절대 수정하지 마
- config.json 값만 채울 것
- 문구는 README.md 5번 "문구 원칙" 을 따를 것
- 결론이나 매수·매도 권유를 넣지 말 것
- 확인되지 않은 값은 "자료 없음" 으로 표기할 것
```

## 디자인을 손볼 때

```
generate.py 의 card1() 함수만 수정해줘.
다른 카드 함수와 디자인 토큰(색상 상수)은 건드리지 마.
좌우 기준선 x=80 / x=1000, 흰 카드 내부 패딩 56 규칙은 유지할 것.
```
