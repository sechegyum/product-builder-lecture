# Claude Code 요청용 프롬프트

## 새 회차 만들기

이것만 보내면 된다. 나머지 수치는 Claude 가 조사한다.

```
카드뉴스 만들어줘.

종목: 모더나 (MRNA)
뉴스: 머크와 공동 개발한 mRNA 암 백신이 임상 3상 목표 달성, 하루 177% 급등
```

링크나 기사 본문을 같이 던져도 된다.

Claude 는 `.claude/skills/snapvest-cardnews/SKILL.md` 순서대로:
이전 회차 보관 → 수치 조사 → 사진 전처리 → config 작성 → 생성 → 렌더 →
출처 정리 → SNS 글귀 → 커밋.

### 사진을 직접 줄 때

파일을 첨부하고 어느 카드에 쓸지만 말하면 된다.
2번(기업) 1000×340, 3번(급등 이유) 1000×372 슬롯이고,
원본이 작아도 `make_photos.py` 가 알아서 맞춘다.

첨부가 없으면 Claude 가 Brandfetch 로 로고를 가져오거나 플레이스홀더로 둔다.

### 참고

- `config.example.json` — 채워진 config 한 벌 (2026.08.20 MRNA 회차)
- `archive/2026-08-20-MRNA/` — 그 회차의 결과물 전체. 이대로 나오면 된다

```
[종목]

시가총액:
거래량 (평균 대비 몇 배):
52주 위치:

[급등·급락 사유]
핵심 한 줄:
상세 (200자 내외):
아직 공개되지 않은 것:
출처:

[지표]
MFI / RSI / 볼린저 %B:
공매도 잔고 변화:

[차트]
최근 46일 OHLCV (없으면 전일 종가와 당일 종가만)
```
