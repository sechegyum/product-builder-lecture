## ★★ 이번 표는 시·고·저가 다 있다 — 처음이다

토스 **웹** 일별 시세라 `일자 · 종가 · 등락률 · 거래량 · 거래대금 · 시가 · 고가 · 저가`
여덟 칸이 전부 나온다. 지난 네 회차는 모바일 화면이라 시·고·저가 없어
전일 종가를 시가로 삼아야 했다. **이번엔 진짜 봉을 그릴 수 있고, MFI 도
진짜 대표가 (고+저+종)/3 으로 낼 수 있다.**

검산 세 가지를 전부 통과했다.

```
① 등락률 체인   16일 최대 오차 0.009%p  → 빠진 거래일 없음 ✓
② OHLC 정합성   저가 ≤ min(시,종) · 고가 ≥ max(시,종)  16일 전부 ✓
③ 거래대금 검산  거래대금÷거래량 = 평균 체결가가 그날 고가·저가 안  16일 전부 ✓
```

**등락률 역산이 필요 없다.** 주가가 $1.66~$3.22 대라 표기 종가만으로
체인이 맞는다. 이번 회차 봉은 전부 실제값이다.

## ★★★ 정정 — 지난 세 회차의 `거래량 8.1배 왜곡` 은 내 오독이었다

MGN(8/20·9/2)과 BDRX(8/25)에서 `거래량이 자기 거래대금과 8.1배 어긋난다` 고
세 번 적었다. **틀렸다. 토스 거래대금 표기 단위를 잘못 읽은 것이다.**

이번 화면에서 09.14 거래대금이 **`$1,460만`** 으로 나온다. 만 단위 표기다.

```
$1,460만 = $14,600,000  ÷ 5,275,352주 = 평균 $2.768   → 고가·저가 안 ✓
$1,460,xxx 로 읽으면      ÷ 5,275,352주 = 평균 $0.277   → 저가 $2.11 보다 한참 아래 ✕
```

**토스는 거래대금이 커지면 만 단위로 바꿔 쓴다.** 모바일 화면에서는 그 칸이
화면 밖으로 잘려 나가는데, 내가 잘린 자리를 천 단위 구분 쉼표로 읽었다.

만 단위로 다시 계산하면 세 날이 전부 정상이다.

```
MGN  08.20   $1,977만 ÷ 144,265,019주 = $0.137  (종가 $0.111)  →  1.24배
MGN  09.02   $2,012만 ÷ 127,151,819주 = $0.158  (종가 $0.130)  →  1.22배
BDRX 08.25   $2,4xx만 ÷  16,610,969주 = $1.445  (종가 $1.180)  →  1.22배
```

**세 날 다 1.22~1.24배다.** 장중에 위에서 놀다 내려 마감한 날의 정상적인
모양이지, 데이터 왜곡이 아니다.

▪ **거래량 표기값은 원래부터 맞았다.** 그래서 MGN·BDRX 카드의 봉과 지표는
  고칠 것이 없다
▪ 다만 두 회차 SOURCES 의 `8.1배 왜곡` 단락은 사실과 다르므로
  `archive/` 쪽 파일에 정정 주석을 달았다
▪ **앞으로 잘린 거래대금 칸을 근거로 데이터가 틀렸다고 쓰지 않는다.**
  단위를 먼저 확인한다
